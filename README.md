# AI-агент с Telegram-ботом

Локальный AI-агент на Python, который понимает задачи обычным языком,
сам выбирает нужный инструмент и умеет работать из терминала и в Telegram.

Проект сделан так, чтобы им мог пользоваться новичок: все настройки лежат
в одном файле `.env`, а агент запускается одной командой.

---

## Что умеет агент

| Возможность | Что делает | Пример запроса |
|---|---|---|
| Веб-поиск | Ищет информацию в DuckDuckGo | «Найди последние новости о Python» |
| Погода | Показывает погоду в любом городе | «Какая погода в Москве?» |
| Криптовалюта | Курс Bitcoin, Ethereum, TON и др. | «Сколько стоит Bitcoin в рублях?» |
| Валюты | Курс и пересчёт USD/EUR/RUB | «Переведи 100 долларов в рубли» |
| HTTP-запросы | Обращается к внешним API | «Сделай GET-запрос на https://api.github.com» |
| Файлы | Читает, пишет и показывает файлы в `workspace/`, понимает `.docx` | «Запиши в notes.txt список покупок» |
| Терминал | Безопасные read-only команды | «Покажи содержимое папки» |
| QR-коды | Создаёт PNG с QR-кодом | «Сделай QR-код на https://example.com» |
| Калькулятор | Считает сложные выражения | «Посчитай (2+3)*sqrt(16)» |
| Напоминания | Сохраняет и присылает напоминания | «Напомни через 30 минут позвонить» |
| Память | Помнит историю диалога | «А что я спрашивал раньше?» |

Агент работает через **OpenAI Function Calling**. Модель сама решает,
какой инструмент вызвать, а проект выполняет вызов и возвращает результат
обратно модели.

## С какими файлами работает агент

Все файловые операции идут только внутри папки `workspace/`.

| Формат | Чтение | Запись | Можно прислать боту |
|---|---|---|---|
| `.txt`, `.md`, `.log`, `.py` | да | да | да |
| `.json` | да | да | да |
| `.csv` | да | да | да |
| `.docx` (Word) | да — извлекает абзацы и таблицы | нет | да |
| `.ini`, `.cfg`, `.toml`, `.yml`, `.yaml`, `.html`, `.xml` | да | да | нет |
| `.xlsx`, `.xls` (Excel) | **нет** | нет | нет |
| `.doc` (старый Word), `.pdf`, `.rtf`, архивы | **нет** | нет | нет |

Что это значит на практике:

- **Word читается.** Из `.docx` достаётся текст абзацев и таблиц — агент может
  сделать саммари, ответить по документу, найти нужное. Работает и с файлами,
  которые вы присылаете боту в чат.
- **Excel пока не читается.** Файлы `.xlsx`/`.xls` агент не откроет — выведет
  сообщение, что формат не поддерживается. Если данные нужны, сохраните лист
  как `.csv` и пришлите его.
- **Сканы не читаются.** Если `.docx` или картинка со сканом не содержат
  текстового слоя, агент честно скажет, что текста в файле нет.
- **Запись — только текстовые форматы.** `.txt`, `.md`, `.json`, `.csv` и
  другие текстовые файлы. Не просите агента «создать .docx» — получится
  некорректный файл.

Лимиты на файлы:

| Ограничение | Значение | Где менять |
|---|---|---|
| Размер файла при чтении | 200 КБ | `max_read_bytes` в `agent/config.py` |
| Размер записываемого текста | 1 МБ | `max_write_bytes` в `agent/config.py` |
| Сколько текста файла уходит в модель | 60 000 символов | `max_file_result_chars` в `agent/config.py` |
| Текст присланного в Telegram документа | 50 000 символов | `MAX_DOCUMENT_TEXT_CHARS` в `agent/bot.py` |
| Размер файла в Telegram | 20 МБ | `MAX_DOCUMENT_BYTES` в `agent/bot.py` |

Примеры запросов про файлы:

```text
Прочитай report.docx и сделай саммари в 5 предложениях
Добавь в notes.txt пункт про дедлайн
Что лежит в папке uploads?
```

В Telegram файл достаточно просто прикрепить к сообщению — агент сам извлечёт
текст и выполнит вашу просьбу из подписи к файлу. Если подписи нет, сделает
саммари.

## Быстрый старт (Windows)

### 1. Откройте терминал в папке проекта

В PowerShell перейдите в папку проекта:

```powershell
cd "C:\Users\user\Desktop\Zerocoder DZ\VPf07. AI-агенты"
```

### 2. Создайте виртуальное окружение

```powershell
py -m venv venv
```

Активируйте его:

```powershell
.\venv\Scripts\Activate.ps1
```

Если PowerShell пишет, что выполнение скриптов запрещено, выполните один раз:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

После этого снова активируйте окружение.

> Можно вообще не активировать venv, а запускать всё через
> `.\venv\Scripts\python.exe ...` — так тоже работает.

### 3. Установите зависимости

```powershell
pip install -r requirements.txt
```

### 4. Проверьте `.env`

В папке уже есть файл `.env` с ключами. Если его нет — скопируйте `.env.example`
в `.env` и заполните значения:

```powershell
Copy-Item .env.example .env
```

Минимально нужны:

```env
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.proxyapi.ru/v1
DEFAULT_MODEL=openai/gpt-4.1-mini
BOT_TOKEN=123456:ABC...
```

`BOT_TOKEN` нужен только для Telegram-бота. Для CLI достаточно ключа LLM.

> `.env` содержит секреты. Не отправляйте его в git и не показывайте другим.

### 5. Запустите CLI

```powershell
python run.py
```

Или задайте один вопрос сразу:

```powershell
python run.py "Сколько стоит Bitcoin в рублях?"
```

### 6. Запустите Telegram-бота

```powershell
python run_bot.py
```

Бот будет работать, пока открыт терминал. Остановить — `Ctrl+C`.

## Настройки `.env` простыми словами

| Переменная | Зачем нужна |
|---|---|
| `OPENAI_API_KEY` | Ключ к LLM. Без него агент не думает. |
| `OPENAI_BASE_URL` | Адрес API. Для ProxyAPI: `https://api.proxyapi.ru/v1`. |
| `DEFAULT_MODEL` | Основная модель, например `openai/gpt-4.1-mini`. |
| `FALLBACK_MODEL` | Запасная модель, если основная не отвечает. |
| `DEFAULT_TEMPERATURE` | «Фантазия» модели: 0 — строго, 1 — свободно. |
| `DEFAULT_MAX_TOKENS` | Максимальная длина ответа. |
| `REQUEST_TIMEOUT` | Сколько секунд ждать ответ LLM. |
| `BOT_TOKEN` | Токен Telegram-бота от `@BotFather`. |
| `TELEGRAM_PROXY` | Прокси для Telegram, например `http://127.0.0.1:10809`. |
| `HTTP_PROXY_URL` | Отдельный прокси для погоды/крипты/поиска. Если пусто — берётся `TELEGRAM_PROXY`. |
| `HISTORY_LIMIT` | Сколько последних сообщений помнить. |
| `MEMORY_FILE` | Путь к файлу памяти. По умолчанию `memory.json`. |
| `REMINDERS_FILE` | Путь к файлу напоминаний. По умолчанию `reminders.json`. |
| `WORKSPACE_DIR` | Папка-песочница для файлов агента. По умолчанию `workspace/`. |
| `LOG_FILE` | Файл логов. По умолчанию `bot.log`. |
| `REMINDER_CHECK_INTERVAL` | Как часто бот проверяет напоминания, в секундах. |
| `MAX_TOOL_ROUNDS` | Сколько инструментов агент может вызвать за один вопрос. |

Лимиты на работу с файлами (`max_read_bytes`, `max_write_bytes`,
`max_file_result_chars`) пока заданы в коде — в `agent/config.py`.
Они описаны в разделе «С какими файлами работает агент».

Если какой-то параметр не указан, используется значение по умолчанию.

После `python run.py` появляется приглашение `Вы:`. Пишите задачу обычным языком.

Примеры:

```text
Вы: Какая погода в Санкт-Петербурге?
```

| Команда | Действие |

## Telegram-бот

### Как получить токен

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте `/newbot`.
3. Придумайте имя и username бота.
4. Скопируйте токен в `BOT_TOKEN` в `.env`.
5. Запустите `python run_bot.py`.

### Команды бота

| Команда | Действие |
|---|---|
| `/start` | Приветствие и список возможностей |
| `/help` | Справка |
| `/clear` | Очистить историю этого чата |
| `/stats` | Статистика памяти |
| `/reminders` | Активные напоминания |
| `/id` | Показать ID чата |

### Особенности

- У каждого чата **своя история** — пользователи не видят контекст друг друга.
- **Можно присылать файлы.** Бот скачает документ, извлечёт текст и выполнит
  просьбу из подписи к файлу. Поддерживаются `.docx`, `.txt`, `.md`, `.csv`,
  `.json`, `.py`, `.log`; скачанные копии лежат в `workspace/uploads/`.
- QR-коды бот присылает картинкой.
- Напоминания бот присылает сам, когда подходит время.
- Если указан `TELEGRAM_PROXY`, бот использует его для подключения к Telegram.
- Повторный запуск бота блокируется: второй экземпляр не стартует, а пишет,
  какой PID уже занимает бота (файл `bot.lock`).

## Память

История хранится в `memory.json` в корне проекта.

Структура упрощённо:

```json
{
  "history": [
    {"role": "user", "content": "Привет"},
    {"role": "assistant", "content": "Привет! Чем помочь?"}
  ],
  "chats": {
    "123456789": {
      "history": [],
      "metadata": {"total_turns": 0}
    }
  },
  "metadata": {
    "total_turns": 1,
    "last_updated": "2026-10-30T12:00:00+00:00"
  }
}
```

- `history` — общая история CLI.
- `chats` — отдельные истории Telegram-чатов.
- Хранятся только последние `HISTORY_LIMIT` сообщений.
- Очистить историю: `/clear` в CLI или в боте.
- `memory.json` создаётся автоматически и не попадает в git.

Напоминания лежат в `reminders.json` и тоже создаются автоматически.

## Инструменты: как они работают

### Погода

1. Название города ищется через Open-Meteo Geocoding.
2. Получаются координаты.
3. По координатам запрашивается текущая погода.
4. Агент отвечает температурой, ветром, влажностью и описанием.

Ключ API не нужен.

### Криптовалюта

Используется бесплатный CoinGecko API. Поддерживаются тикеры (`btc`, `eth`, `ton`)
и полные названия (`bitcoin`, `ethereum`). Валюты: `usd`, `eur`, `rub` и другие.

### Валюты

Используется `open.er-api.com`. Можно узнать курс и сразу пересчитать сумму.

### Веб-поиск

Используется библиотека `ddgs` (DuckDuckGo). Агент возвращает заголовки,
ссылки и краткие описания.

### Файлы

Агент работает только внутри `workspace/`. Нельзя прочитать `.env`,
системные файлы или выйти через `../`. Лимиты: 200 КБ на чтение и 1 МБ на запись.

Поддерживаемые форматы — в разделе «С какими файлами работает агент».
Коротко: текст (`.txt`, `.md`, `.log`, `.py`, `.ini`, `.yml`, `.html`…),
`.json`, `.csv` и Word `.docx`. Excel (`.xlsx`, `.xls`), старый `.doc`,
PDF и архивы не поддерживаются.

Инструменты:

- `read_file` — прочитать файл. Для `.docx` извлекает абзацы и таблицы,
  для `.json` возвращает красиво отформатированный текст.
- `write_file` — записать или дописать текст (`append`).
- `list_directory` — показать содержимое папки.

Текст прочитанного файла уходит в модель целиком (до 60 000 символов),
поэтому саммари строится по всему документу, а не по первым абзацам.

### Терминал

Разрешены только безопасные команды чтения:

- `ls`, `dir`, `pwd`
- `cat`, `type`
- `echo`
- `where`, `which`
- `python --version`, `pip --version`
- `git status`
- `date`, `whoami`, `uname`, `ver`

Опасные команды, удаление, запуск произвольных скриптов и shell-операторы
(`|`, `&`, `>`, `<`, `;`) запрещены.

### QR-код

PNG сохраняется в `workspace/`, в Telegram отправляется фотографией.

### Калькулятор

Считает без `eval()`: поддерживаются `+ - * / // % **`, `sqrt`, `sin`, `cos`,
`log`, `factorial`, `pi`, `e` и другие функции.

### Напоминания

Формат времени:

- `+30m` — через 30 минут;
- `+2h` — через 2 часа;
- `2026-10-31 18:00` — конкретное время;
- `2026-10-31T18:00:00` — ISO 8601.

Бот проверяет напоминания каждые `REMINDER_CHECK_INTERVAL` секунд.

## Частые проблемы

### «В .env не задан OPENAI_API_KEY»

Проверьте, что файл `.env` лежит в корне проекта и в нём есть строка
`OPENAI_API_KEY=...` без пробелов вокруг `=`.

### Ошибка 401 или 403 от LLM

Ключ неверный, закончился или не подходит к выбранному `OPENAI_BASE_URL`.
Проверьте ключ в личном кабинете ProxyAPI/OpenAI.

### Ошибка 404 «model not found»

Модель указана неверно. Посмотрите список моделей у провайдера и обновите
`DEFAULT_MODEL` или `FALLBACK_MODEL`.

### Не подключается Telegram

- Проверьте `BOT_TOKEN`.
- Если нужен прокси, заполните `TELEGRAM_PROXY`.
- Убедитесь, что прокси запущен.
- Не запускайте два экземпляра бота одновременно — Telegram выдаст `Conflict`.

### В логе ошибка `Conflict: terminated by other getUpdates request`

Значит, запущено несколько копий бота. Telegram отдаёт сообщения только одной
сессии, остальные отваливаются, а сообщения достаются процессу со старым кодом.

Решение — остановить все копии и запустить одну:

```powershell
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like '*run_bot.py*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }

.\venv\Scripts\python.exe run_bot.py
```

Свежие версии проекта сами блокируют второй запуск — появится сообщение с PID
уже работающего бота. Если бот «упал» и блокировка осталась, удалите `bot.lock`.

### Бот молчит в ответ на присланный файл

- Убедитесь, что бот перезапущен после обновления кода.
- Проверьте расширение: `.xlsx`, `.pdf`, `.doc` и `.rtf` не поддерживаются.
- Посмотрите последние строки `bot.log` — там видно, на каком шаге сбой.
- Частая причина — несколько копий бота (см. ошибку `Conflict` выше).

### Не работает DuckDuckGo или CoinGecko

Сервисы могут ограничивать запросы или быть недоступны из вашей сети.
Агент сначала пробует через прокси, затем напрямую. Подождите или попробуйте
другой запрос.

### Русский текст в консоли выглядит странно

CLI включает UTF-8 автоматически. Если проблема осталась, запустите из
Windows Terminal или PowerShell 7.

### PowerShell не даёт активировать venv

Выполните:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Или запускайте Python напрямую:

```powershell
.\venv\Scripts\python.exe run.py
```

## Безопасность

- `.env` не коммитится в git.
- Файловые операции ограничены папкой `workspace/`.
- Терминальные команды — только из белого списка, без shell.
- HTTP-инструмент не ходит на localhost и приватные IP.
- Агент не выполняет произвольный код из ответа модели.
- `memory.json` и `reminders.json` не коммитятся — это пользовательские данные.

## Примечания

- LangChain в проекте не используется: агентный цикл написан напрямую на
  OpenAI SDK. Так меньше зависимостей, проще читать код и стабильнее работает
  интеграция с разными OpenAI-совместимыми провайдерами.
- При ошибке основной модели агент автоматически пробует `FALLBACK_MODEL`.
- Логи пишутся в `bot.log`.
- Проект можно расширять: добавьте функцию в `agent/tools/`, опишите её в
  `agent/tools/registry.py` — и модель сможет её вызывать.
